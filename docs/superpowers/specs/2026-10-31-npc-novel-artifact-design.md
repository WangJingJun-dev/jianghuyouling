# 往事成书：功能与呈现需求

## 功能定义

「往事成书」把太吾与某位人物的交往素材整理成人物小说，并提供两种成果：

- 可离线翻阅的古书式 HTML 书稿。
- 符合游戏原生模板的真实秘闻。

## 当前流程

1. 玩家从人物详情或「杂务」进入「往事成书」。
2. Mod 固定当前世界、太吾和 NPC 身份，收集此人的单聊、实际参与的群聊及长期记忆。
3. 玩家调整写作要求并开始写作；Mod 按上下文预算整理素材，清除内部提示、思考过程和敏感信息。
4. 大模型生成人物小说，Mod 清理正文后显示预览，并按人物保存本地草稿。
5. 玩家目前只能导出 TXT，没有古书式 HTML 或原生秘闻成果。

## 目标流程

1. 在现有素材之外加入本体人物经历，保持人物、世界和回档隔离。
2. 小说生成后先预览，不自动修改游戏状态。
3. 玩家可将小说导出为原创古书式 HTML，用于离线翻阅。
4. 玩家也可单独执行「辑为秘闻」，把符合原生模板的真实经历写入游戏。
5. 不支持原生秘闻模板的内容仍可作为书稿阅读，但不得伪报已生成游戏内成果。

## 写作素材

- 保留当前人物的单聊、实际参与群聊和长期记忆。
- 加入 `LifeExperienceSummaryService` 整理后的本体人物经历。
- 保持世界、太吾和 NPC 身份隔离；回档或切换人物后不得复用旧快照。

## 原生秘闻

- 小说生成不自动改写游戏状态。
- 窗口提供独立的「辑为秘闻」动作，由玩家预览后明确触发。
- 只处理已经核对类型、参数和原生写入方法的实际经历。
- 后端使用 `SecretInformationCollection` 与 `InformationDomain.AddSecretInformation` 创建原生秘闻。
- 本体只提供固定事件模板，不能把任意长篇小说直接保存为秘闻。
- 没有匹配模板、参数不足或写入结果无法确认时，明确报告未生成，不伪造成功。
- 小说文本与秘闻模板分开保存；不得把小说内容伪装成本体秘闻正文。
- 重复点击不得重复创建同一秘闻。

## 古书式 HTML

- 「往事成书」的书稿导出为 HTML。
- 使用 Mod 内置的确定性渲染器，不调用外部 CLI，不要求玩家安装开发工具。
- 不使用 `answer-me-with-html`，不指向或套用外部 GitHub 模板。
- 输出一个可直接离线打开的 HTML 文件，不依赖网络、外部字体、远程图片或 CDN。
- 小说正文必须作为数据处理；不得直接执行模型返回的 HTML、CSS 或 JavaScript。
- 沿用当前世界隔离、敏感信息清理、长度限制和原子写入规则。

## 原创视觉

- 从《太吾绘卷》的纸张、墨色、装帧和文字氛围出发，独立设计书籍页面。
- 不采用通用 Agent 客户端、数据卡片、现代仪表盘、玻璃拟态或技术文档式排版。
- 封面包含古朴书名、人物名、克制印章和简洁装帧，不使用现代应用标题栏。
- 纸张使用低饱和米纸色和轻微旧纸质感，正文使用清晰墨色；纹理不得损害可读性。
- 色彩以纸色、墨色、旧木色为主，少量朱砂色点缀，避免高亮金色和荧光色。
- 字体优先使用玩家本机已有的楷体、仿宋或宋体回退链，不下载字体。
- 封面与正文有明确区别；长文按书页组织，页边距、行距和每页字数适合连续阅读。
- 装饰仅使用细线、书口、装订线、页码和克制印章，不堆砌龙纹、祥云或无意义边框。
- 页面包含人物名、正文和生成时间，不显示 Agent 状态、Token、调试信息或内部提示。

## 阅读交互

- 提供上一页、下一页和页码定位；长篇内容不得全部挤在一个现代滚动面板中。
- 桌面可使用双页展开，窄屏退化为单页；无翻页动画时仍能完整阅读全部正文。
- 翻页动画轻缓、可关闭，不影响选择文字和复制。
- 可提供横排与竖排选项，但默认排版必须保证长篇中文可读性。
- 禁用 JavaScript 后仍能连续阅读完整正文。

## 离线安全

- 所有必需样式、脚本和纹理均内嵌或由本地代码生成，不发出网络请求。
- 内嵌脚本只承担分页、翻页和排版切换；模型正文必须 HTML 编码并安全传入。
- 禁止模型正文注入脚本、事件属性、外部资源或导航。

## 验收标准

1. 小说素材能体现本体人物经历，且不会混入其他人物或旧存档内容。
2. 支持的经历能生成可在本体秘闻界面查看的真实秘闻。
3. 不支持的经历不会生成错误或无关秘闻，界面说明具体原因。
4. 未确认的游戏写入不得改变存档；重复点击不得重复创建同一秘闻。
5. HTML 可直接离线打开，封面、纸张、墨色和装帧形成明确古书观感，而非通用说明页。
6. 长文分页、前后翻页、窄屏单页、文字选择与复制均正常；禁用 JavaScript 后正文仍可完整读取。
7. 页面不发出网络请求，模型正文无法注入脚本或外部资源。
8. 桌面浏览器中的实际古书视觉效果符合上述要求。
9. 前后端构建、现有测试和新增回归检查通过。
